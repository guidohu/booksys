# booksys frontend

## Project setup

```
npm install
```

### Compiles and hot-reloads for development

```
npm run serve
```

This will expect the backend to run on port :9090. All request to the API will be proxied.

### Compiles and minifies for production

```
npm run build
```

### Lints and fixes files

```
npm run lint
```
